## Safeguards and abuse tests

The node decides where a folder may be made: a new node.toml key for the projects folder and `workspace_roots` for a chosen destination; the master sends a name and, in host mode, a path the node checks as it checks `cwd` today (canonical, inside the roots, not the data directory, not a symlink out).
The slug is made on the node from a bounded name (`[a-z0-9-]`, no dots, no separators); a taken name gets new random characters, never an overwrite.
Abuse tests: a name of `../x`, a destination outside the roots or over the data directory, a symlinked parent, two creations at once, a hostile master asking for a folder outside what node.toml allows, a second user of the workspace.
