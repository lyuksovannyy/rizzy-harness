# T48

## Threat

The environment line (ADOPTION_PLAN X.8): the node's clock, OS and the session repository's git branch reach the model in every agentic turn's message, and the branch is the repository's text: a cloned repository or a prompt-injected agent writes `.git/HEAD` (or a `.git` file naming another git folder) to plant text, to make the node wait on a FIFO, or to read a file outside the session's folders through a link.

## Mitigation

`HEAD` (and a worktree's `.git` file) read through `harness_tools::inside::read_inside` like the instruction files: only a regular file whose real path is inside the granted folder and in no protected folder, opened without following a final link or waiting on a FIFO, at most 512 bytes, in a 5 s bound; no `git` process.
Only `ref: refs/heads/<name>` or a 40/64-hex id is used: the name is made one line, at most 120 characters, quotation marks read as `'` (`shown_name`), inside quotes under a `[harness]` line; anything else is "not read".
A git folder outside the session's folders is not read and not named.
Recorded on `turn_started.environment` (written by the node only, never from the protocol).
Tests: `crates/node/src/environment.rs` (FIFO, link out, hostile name, worktree inside/outside); `node/tests/repo_instructions.rs`.
Residual: the branch name is still text the repository chose, within those bounds.
