# T64

## Threat

**A person's `/compact`** (ADOPTION_PLAN X.20): a summary of the chat made between turns at its owner's request, with words of theirs on what to keep. (1) Someone else's request: another member, an admin or a routine summarising a chat that is not theirs (a summary replaces what the model sees). (2) A prompt-injected model or a routine triggering it (each one costs a model call and replaces context). (3) The focus text overriding the summary prompt's rules (tool output stays data) or forging a harness line or a `User:` part. (4) Cost: a person or a script hammering it. (5) A summary written while a turn runs, or a turn starting on a half-written one.

## Mitigation

(1) `POST /api/sessions/{id}/compact` runs the checks of a prompt (`require`, `visible_session`, `agentic_gate`): the owner or the API token only, everyone else gets 404 (`crates/master/tests/it/compact_http.rs`); the master forwards `session.compact` only to a node that announced `compact`. (2) It is no tool and no prompt text: only that route sends it, so nothing a model writes, no routine and no callback can. (3) The focus is the person's words quoted under its own `Focus:` label like every other part of the summariser's transcript (T38): a label or `[harness]` line inside it is quoted text; the prompt says the focus shifts emphasis only, within its rules; the node scrubs it and cuts it to 2,000 characters before the summariser and the log see it (the master refuses more than 64 KiB). (4) One at a time per chat (`COMPACT_BUSY`); the summariser's breaker (A.7) inside one; two `compact_failed` since the last turn or summary refuse the next; the summary call is counted in the chat's usage. (5) Refused while a turn runs (`COMPACT_TURN_RUNNING`); no turn starts while it runs (`claim_turn` refuses with `COMPACTING`, a callback is told busy and asked again later, a hand-off note is cancelled); the summary is appended only if the log's head is still what it read (`append_if_head`), else `compact_failed`;
Stop and a delete cancel it.
Tests: `crates/node/tests/compact.rs`, `agent-native/src/manual_compact.rs`. (6) Queued messages (review M1): `/compact` is refused while a message the person sent during the last turn waits to be read (`COMPACT_PENDING`), since the turn that reads it may be about to claim the slot; and a `/compact` that ends with messages waiting starts that turn, as a turn's end does (`cli/tests/compact_queue.rs`, a test hook holding the window open). (7) The name: `/compact` is reserved (`harness_tools::skills::RESERVED`): a skill called `compact` is still listed to the model and loads through the `skill` tool, but `/compact` at the start of a message never invokes it (T46).
**Residual:** the focus can still steer what the summary keeps (that is its job): a person who asks it to drop facts loses them from what the model sees (the log and the chat keep everything).
Anything that joins the log while it runs (a background command's end, an undo, an approval-mode change) discards the summary as "the chat changed" (`compact_failed`), which counts toward the two-failure breaker.
Queued messages left unread after a restart or a Stop refuse `/compact` until the person's next message reads them.
